# Triage Checklist

## Identity
- [ ] Absolute path recorded
- [ ] SHA-256 computed
- [ ] Processor / format noted if known

## Inventory
- [ ] Function list obtained (count, entry points)
- [ ] Strings extracted
- [ ] Symbols / imports / exports listed

## Survey signals
- [ ] Network-related strings or imports
- [ ] Crypto constants or related imports
- [ ] Process / injection / anti-debug indicators
- [ ] File / registry / persistence paths
- [ ] Large or complex functions flagged for later decompilation

## Output
- [ ] Evidence identifiers or offsets cited
- [ ] Limitations stated (timeout, incomplete analysis, no runtime)
- [ ] Prioritized next steps listed
- [ ] Temporary projects cleaned
